Manuscript Downloader
for vHMML

Sign in once, then paste vHMML links. Check the manuscript names. Save the page images and a PDF for each manuscript.

First, extract the ZIP. Keep all the files together in a writable folder such as Downloads. This is a Python script with easy launchers, so you need Python installed once. Get Python from python.org — version 3.11 or newer with Tcl/Tk; 3.13 is a suitable choice.

On Windows

  1. Install Python if needed. Include Tcl/Tk and select “Add Python to PATH” if offered.
  2. Open the extracted folder in File Explorer.
  3. Double-click Start-Windows.bat.

On Mac

  1. Install Python from python.org if needed.
  2. Open the extracted folder in Finder.
  3. Double-click Start-Mac.command.

The first launch installs its packages automatically in this folder. Leave the setup window open until the downloader appears.

In the downloader window

  1. Sign in once. Choose “Sign in (normal browser)” and sign in on vHMML’s Reading Room home page. You can sign in before entering any links. No individual viewers need to be opened.
  2. Import login once. Follow the app’s instructions to copy the Reading Room home page request’s Cookie header into its hidden field. It treats the home-page login flag as a hint, then checks the actual manifests when you choose Preview. An unconfirmed home-page check does not discard the import. Your imported session covers later batches until it expires or you close the app.
  3. Paste your links. Use Reading Room or IIIF manifest links, one per line. The example button fills in three public catalog links; their images may require login.
  4. Preview manuscripts. Check the names and page counts. Choose where to save them.
  5. Download. The app saves one folder per manuscript, with page images, a PDF, and source metadata. Choose “Images only” if you do not want a PDF.

Your normal browser still needs one manual login import. The optional separate browser can copy its session after sign-in, but Cloudflare may reject that browser.

Default destination: Downloads → vHMML Downloads. Use “Open save folder” to find the results.

To resume: use the same links and save folder. Completed images are checked and reused. A failed or stopped run keeps completed pages.

If you need help

The browser is signed in but the app cannot confirm it

In v4, an unconfirmed home-page check no longer blocks import. Paste your links and choose Preview. Cookie tokens are preserved, and refreshed www.vhmml.org session cookies replace the imported value without duplication.

If Preview is denied, click Copy diagnostics. This copies counts, presence of the session cookie, the login hint, and HTTP status codes. It excludes cookie values, passwords, account details, and full URLs. The report can be shared to investigate the next step; the cookie itself should not be shared.

The Mac launcher will not open

If it opens as text, choose Open With → Terminal. If permission is denied, open Terminal, type bash with a space, drag Start-Mac.command into Terminal, and press Return.

If macOS blocks a downloaded script, inspect the package and use the specific Finder Open or Privacy & Security Open Anyway option if you trust it. Do not disable system security globally.

The app asks me to sign in again

Choose “Sign in (normal browser),” sign in, and refresh the Reading Room home page. Return to the app and choose “Import login.” Copy the Cookie header from the readingRoom/ document request; no viewer is needed. Login lasts only for this run and can expire on the server. The app cannot grant access that your account does not have.

If the optional separate browser shows Cloudflare “Verification failed,” click Stop and use the normal-browser route. Automated browsers may be rejected even with manual interaction. If verification also fails in your normal browser, update it and test without extensions or a VPN. See Cloudflare’s troubleshooting guide. Session import does not guarantee that the image server will accept downloader requests.

A Reading Room link does not resolve

Open the manuscript in vHMML. Use the viewer’s information button to copy its IIIF Link, such as https://www.vhmml.org/image/manifest/125659, and paste that full link instead. The downloader does not guess IDs.

I use Linux or prefer the terminal

Linux needs Python 3.11+, Tkinter, and venv. Run sh Start-Linux.sh. Browser sign-in may need additional Linux browser libraries.

For terminal mode, run python3 bootstrap.py --cli --browser-login "MANUSCRIPT_URL" on Mac/Linux, or py -3 bootstrap.py --cli --browser-login "MANUSCRIPT_URL" on Windows. Replace MANUSCRIPT_URL with the full link. More options are in READ-ME-FIRST.md.

Designed for common vHMML IIIF manuscripts with one image per page. Requires your own account access where applicable. Offline download and PDF tests and the Mac window were checked; a user has reported a successful signed-in run. Native Windows execution and live account access are not covered by automated tests. This package is source code with launchers, not a signed standalone app.
